V1.0.02026-10-22 · OhmShield 專案化

網頁門牌、漏洞情報、電腦三條線合成一個總分＋紅黃綠燈＋待處理清單；同一套 core 引擎、同一份資料、同一個介面頁，兩個入口：桌面視窗程式（右下角盾牌常駐、離線可用）與 OSCLAW（手機遠端、LINE 查詢）。所有寫入動作加檔案鎖；頁面可直接觸發巡檢與安全修補。

前身2026-10-22 · 資安 IP 封鎖中心 V1.0～V1.3

IP 情報引擎（PTR＋RDAP＋行為判定 7 種身分、惡意掃描自動封鎖、搜尋引擎官方網域驗證）；漏洞情報（OSV.dev＋CISA KEV、一次一個 --no-deps 安全修補、首輪對外漏洞 212→112）；起因 HITCON PHP2Shell 警示。完整紀錄見 CHANGELOG.md。

伺服器端（你的網站）

  • 網站把每個請求寫成 JSON Lines（或用 nginx／Apache combined 格式），並拒絕 blocked_ips.json 裡的 IP。
  • 建議另外做速率限制（例如同 IP 60 秒內超過 30 次頁面導覽就封）。
  • 封鎖、解封、巡檢、修補都經過 core 的檔案鎖，視窗程式和 OSCLAW 同時按也不會打架。

IP 情報引擎（全自動）

  • 排程每小時執行 core/ip_intel.py run：每個新 IP 反查主機名（PTR）＋網段擁有者（RDAP），同網段共用快取，7 天重查一次。
  • 依證據自動判定身分並寫備註：自家／站長裝置（推定）／平台連結預覽（LINE、FB…）／搜尋引擎（Google、Bing 會驗證官方網域，冒充的抓出來）／一般訪客／雲端主機／惡意掃描。
  • 惡意掃描自動封鎖（reason=auto:intel），自家、站長、平台、搜尋引擎永不自動封；誤封可在封鎖清單一鍵解封。
  • 結果檔：ip_notes.json；紀錄：ip_intel.log。

本頁判讀（只影響顯示）

  • 自家：UA 是你自己的監控程式（config 的 self_ua_markers），或該 IP 曾送出這些 UA。
  • 預覽爬蟲：facebookexternalhit、LINE、bot、spider、crawl、curl、python、Go-http、scanner 等。
  • 系統 API：/api/ 等程式輪詢。
  • 風險分數：掃描路徑（.env、wp-、phpmyadmin、.git、.php、cgi-bin…）+40、每分鐘峰值 ≥20 +25、機器人 UA +15、無 UA +15、頁面種類 ≥25 +10。≥60 高、≥30 中。

說明
