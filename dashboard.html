Change list 版本紀錄

v1.0.02026-10-22 · 首次開源

IP Intel（PTR＋RDAP＋行為判定 7 種身分、惡意掃描自動封鎖、搜尋引擎官方網域驗證）＋Vuln Watch（OSV.dev＋CISA KEV、安全自動修補）＋本儀表板。完整紀錄見 CHANGELOG.md。

伺服器端（你的網站）

  • 讓網站把每個請求寫成 JSON Lines（或直接用 nginx／Apache combined 格式），並拒絕 blocked_ips.json 裡的 IP。
  • 建議另外做速率限制（例如同 IP 60 秒內超過 30 次頁面導覽就封）。
  • 封鎖／解封 API（選填）務必加管理員驗證。

IP 情報引擎（全自動）

  • 排程每小時執行 ip_intel.py run：每個新 IP 反查主機名（PTR）＋網段擁有者（RDAP），同網段共用快取，7 天重查一次。
  • 依證據自動判定身分並寫備註：自家／站長裝置（推定）／平台連結預覽（LINE、FB…）／搜尋引擎（Google、Bing 會驗證官方網域，冒充的抓出來）／一般訪客／雲端主機／惡意掃描。
  • 惡意掃描自動封鎖（reason=auto:intel），自家、站長、平台、搜尋引擎永不自動封；誤封可在封鎖清單一鍵解封。
  • 結果檔：ip_notes.json；紀錄：ip_intel.log。

本頁判讀（只影響顯示）

  • 自家：UA 符合 OGS_CONFIG.selfUa，或該 IP 曾送出這些 UA。
  • 預覽爬蟲：facebookexternalhit、LINE、bot、spider、crawl、curl、python、Go-http、scanner 等。
  • 系統 API：/api/ 等程式輪詢。
  • 風險分數：掃描路徑（.env、wp-、phpmyadmin、.git、.php、cgi-bin…）+40、每分鐘峰值 ≥20 +25、機器人 UA +15、無 UA +15、頁面種類 ≥25 +10。≥60 高、≥30 中。
